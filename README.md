# SE Intern Game ฉบับ 0.4

เล่นเกม: https://chontipan.github.io/swe-intern-game-v03/

เกมสถานการณ์งานวิศวกรรมซอฟต์แวร์ครอบคลุม Developer, Business Analyst, QA / Tester, UX/UI Designer และ DevOps / SRE รวม 80 สถานการณ์
เปิด index.html ในเบราว์เซอร์ได้โดยไม่ต้องติดตั้งแพ็กเกจ ชื่อ repo และ URL คงเดิม แต่เกมปัจจุบันเป็นฉบับ 0.4

## การปรับในฉบับ 0.4

เพิ่มแหล่งเฉพาะทางเรื่อง SLO/percentile, ความเสี่ยง GenAI, usability testing, dependency caching และ canary releases พร้อมชี้หัวข้อและขอบเขตการนำมาใช้ เพิ่มความชัดเจนของ audit trail และแยกหลักการจากนโยบายสมมติในสถานการณ์

บทสรุปหลักการแสดงหลังทุกทางเลือกเหมือนกัน ผู้เล่นจึงมีโอกาสเรียนรู้ครบ ไม่ว่าตอบถูกหรือผิด

ข้อสอบและเอกสารผู้เชี่ยวชาญฉบับ 0.4 จัดเก็บแยกจาก repo นี้ มีการปรับคำชี้แจง 4 ด้าน นิยาม audit trail เกณฑ์คะแนนบางส่วน และบรรณานุกรม ไม่เผยแพร่ข้อสอบหรือเฉลยบนเว็บ

## สถานะ

ฉบับร่างพร้อมส่งผู้เชี่ยวชาญตรวจ วันที่ 13 พฤศจิกายน 2569 ยังไม่ผ่านการตรวจความตรงหรือการทดลองยืนยันคุณภาพเครื่องมือ คะแนนเกมไม่ใช่คะแนนแบบทดสอบและไม่รับรองความพร้อมฝึกงานทุกมิติ

แผน R3 ใช้ผู้เรียน 40 คน 4 สัปดาห์ ทุกคนเรียนครบ 5 บทบาท เวลา 16 สัปดาห์ในเกมเป็นเวลาจำลอง

## ที่มา

พัฒนาต่อจาก https://github.com/chontipan/swe-intern-game ที่ commit eecd02b98998d2c7e71935290219f91d4f2d3583 และฉบับปรับปรุงสำหรับการวิจัย แหล่งอ้างอิงใช้รองรับหลักการ ส่วนบริบทและคะแนนเป็นข้อเสนอที่ต้องให้ผู้เชี่ยวชาญตรวจ
