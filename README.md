# SE Intern Game — ฉบับ 0.3

เกมสถานการณ์งานวิศวกรรมซอฟต์แวร์สำหรับเตรียมการทดลองทางการศึกษา ครอบคลุม Developer, Business Analyst, QA / Tester, UX/UI Designer และ DevOps / SRE

เปิด `index.html` ด้วยเว็บเบราว์เซอร์เพื่อเล่น ไม่ต้องติดตั้งแพ็กเกจ

## สิ่งที่ปรับในฉบับนี้

- สถานการณ์ 80 เรื่อง พร้อมบทสรุปหลักการหลังตอบที่ผู้เล่นได้รับเหมือนกันทุกทางเลือก
- เสริมบทเรียน SE จำนวน 20 เรื่อง รวม transaction/rollback, request identifiers, retries, p95 และ idempotency
- ชี้เงื่อนไข release ใน OPS-04 ให้ชัดเจน: canary ไม่ทดแทนผู้รับเหตุและ rollback ที่ตรวจแล้ว
- แสดงแหล่งอ้างอิงประกอบหลักการในเกม

## สถานะการวิจัย

ฉบับร่างสำหรับผู้เชี่ยวชาญตรวจ วันที่ 13 พฤศจิกายน 2569 ยังไม่ได้ผ่านการตรวจความตรงหรือทดลองยืนยันคุณภาพเครื่องมือ คะแนนในเกมไม่ใช่คะแนนแบบทดสอบ และไม่รับรองความพร้อมฝึกงานจริง

แผนทดลองเบื้องต้นใช้ผู้เรียน 60 คน ระยะเวลา 2 เดือน ให้ทุกคนเรียนครบทั้ง 5 บทบาท เวลาจำลอง 16 สัปดาห์ในเกมไม่ใช่ระยะเวลาทดลองจริง

ข้อสอบ เฉลย เอกสารผู้เชี่ยวชาญ และข้อมูลผู้เข้าร่วมเก็บแยกจาก repo นี้ เพื่อควบคุมการเข้าถึงก่อนและระหว่างการทดลอง
